SVG autotrace (черновик)
========================
Сделано из точных PNG designer-pack через vtracer.
Это НЕ ручной вектор: линии упрощены, свечения стали плашками цвета.

Для продакшена дизайнер обычно доводит в Figma/Illustrator
или перерисовывает поверх этих SVG.

Файлы:
  *-detailed.svg  — больше деталей
  *-clean.svg     — сильнее упрощён (меньше цветов / спеклов)
