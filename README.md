# Aegis Gate

Публичный сайт приложения Aegis Gate: [aegis-gate.ru](https://aegis-gate.ru/).

В этом репозитории только лендинг: страницы, стили, тексты, юридические документы и настройки ссылок. Исходников клиента здесь нет.

Файлы сайта лежат в каталоге [`website/`](website/).

Локальный просмотр:

```bash
cd website
python -m http.server 8765
```

Откройте http://127.0.0.1:8765/

Ссылки на скачивание, кабинет, Telegram и пинги задаются в `website/config.js`. Пока сборок нет, кнопки скачивания остаются неактивными.
