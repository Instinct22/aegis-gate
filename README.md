## Сайт

На сайте:

- что делает Aegis Gate и чем он удобнее обычных клиентов;
- доступные страны и заготовка под пинг с сервера;
- бесплатный пробный период: 3 дня полного доступа;
- скачивание для Windows, Android и macOS — кнопки включатся, когда появятся файлы;
- условия использования, конфиденциальность и условия оплаты;
- поддержка: `support@aegis-gate.ru`.

Локально:

```bash
cd website
python -m http.server 8765
```

Откройте http://127.0.0.1:8765/

Публичные ссылки (скачивание, кабинет, Telegram, пинги) задаются в
`website/config.js`.

## Приложение

Aegis Gate — клиент для Android, Windows и macOS. Он подключает устройство по
выданной конфигурации: профиль добавляется по ссылке, из файла или QR-кода,
обновляется автоматически, а статус, скорость и направление видны на главном
экране.

Возможности:

- один подход на телефоне и компьютере;
- выбор страны и быстрое стабильное соединение;
- системный режим, TUN, DNS и дополнительные параметры ядра;
- статистика трафика, список подключений и журнал;
- светлая и тёмная темы;
- резервное копирование настроек и синхронизация через WebDAV.

Ссылок на установщики пока нет: они появятся на сайте и в релизах, когда
сборки будут готовы.

### Как будет выглядеть установка

| Платформа | Какой файл выбрать |
| --- | --- |
| Android | `android-arm64-v8a.apk` для большинства устройств; `armeabi-v7a.apk` для старых 32-битных; `x86_64.apk` для совместимых эмуляторов |
| Windows | `windows-amd64-setup.exe` для установки или `windows-amd64.zip` для переносной версии |
| macOS на Apple Silicon | `macos-arm64.dmg` |
| macOS на Intel | `macos-amd64.dmg` |

**Android.** Откройте APK и подтвердите установку. При первом подключении
разрешите приложению создать VPN-подключение.

**Windows.** Запустите установщик и откройте Aegis Gate из меню «Пуск». Если
режиму нужны дополнительные права, система спросит их при включении.

**macOS.** Откройте DMG и перенесите Aegis Gate в Applications. Если система
остановит первый запуск, разрешите приложение в «Системные настройки →
Конфиденциальность и безопасность».

### Быстрый старт

1. Получите конфигурацию у своего поставщика.
2. Откройте **Профили** и нажмите **Добавить профиль**.
3. Выберите способ: **URL**, **файл** или **QR-код**.
4. Сделайте профиль активным.
5. На главном экране нажмите кнопку запуска и подтвердите системный запрос.

Новый пользователь получает 3 дня полного доступа, чтобы проверить приложение
у себя.

## Если что-то не работает

Убедитесь, что профиль выбран, разрешение выдано, а срок конфигурации не
закончился. Затем синхронизируйте профиль и перезапустите подключение.

Если после изменения настроек пропала сеть, остановите подключение, верните
последние параметры и запустите снова. Для диагностики откройте **Инструменты →
Журналы**.

Пишите на `support@aegis-gate.ru`. Не присылайте личные ссылки, токены и другие
секреты.

## Безопасность

Добавляйте только конфигурации из доверенного источника. Перед отправкой
журналов удаляйте из них адреса профилей и токены. Aegis Gate не хранит трафик
и историю пользователей.

## Сборка клиента из исходного кода

Клиент собирается из этого репозитория. Нужны Flutter, Go и инструменты
целевой ОС.

```bash
git clone --recurse-submodules https://github.com/Instinct22/aegis-gate.git
cd aegis-gate
flutter pub get
flutter test
dart setup.dart android   # или windows, macos, linux
```

Если репозиторий склонирован без подмодулей:

```bash
git submodule update --init --recursive
```

Перед изменениями:

```bash
flutter analyze --no-fatal-infos
flutter test --reporter expanded
```

Сайт отдельно собирается из каталога `website/` (статические файлы или Docker,
см. `website/README.md`).
