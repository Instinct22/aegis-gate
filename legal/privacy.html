Политика конфиденциальности

Редакция от 28 ноября 2026 года. Команда Aegis Gate team обрабатывает данные пользователей сайта aegis-gate.ru, личного кабинета и обращений в поддержку. Связаться с командой можно через @Instinct22.

1. Личный кабинет и подписка

При входе через Google или Яндекс сервис получает идентификатор пользователя у выбранного провайдера и адрес электронной почты либо имя профиля. Эти данные позволяют найти ваш кабинет при повторном входе и привязать второй способ авторизации. Файл cookie с идентификатором сессии поддерживает вход в кабинет.

Для выдачи доступа сервис хранит внутренний номер аккаунта, дату создания, данные привязанных способов входа, идентификатор подписки и персональную ссылку подключения. Содержимое VPN-трафика и историю посещений сайтов сервис не хранит.

2. Оформление и оплата

В форме заказа вы указываете свой email. Пока оплата недоступна, адрес используется только для проверки формы, не сохраняется в истории заказов и не передаётся в Platega. После подключения кассы при создании транзакции сервис передаст Platega ваш email для идентификации покупателя, сумму в рублях и описание выбранной подписки. Платёжные реквизиты вводятся на стороне платёжного провайдера.

3. Поддержка и технические данные

Для ответа на обращение команда обрабатывает ваш контакт в Telegram, сообщения и материалы, которые вы сами присылаете. Веб-сервер ведёт технический журнал запросов, включая IP-адрес, время, запрошенную страницу и код ответа. Это помогает находить ошибки и обеспечивать работу сайта.

4. Хранение и передача

Данные кабинета и подписки нужны для предоставления доступа, обращения — для решения вопросов пользователя. Сервис хранит данные до достижения соответствующей цели либо в течение обязательного срока, если он установлен законом. Технический журнал сайта ротируется. Доступ к данным получают лица, обслуживающие сервис, в объёме, необходимом для работы. Для входа используются выбранный вами провайдер авторизации, для размещения сервиса — инфраструктура хостинга. Передача уполномоченным органам возможна в случаях, предусмотренных законом.

5. Обращения по данным

Чтобы узнать, какие сведения относятся к вашему аккаунту, уточнить их или запросить удаление, напишите @Instinct22 и укажите номер кабинета. Команда может попросить подтвердить принадлежность аккаунта. Актуальная редакция политики размещается по этому адресу.
